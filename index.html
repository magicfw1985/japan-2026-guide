① THE皇家公园 CANVAS 神户三宫（Day 1-3）

📍 出口（重要）：最近的三宫站地铁口是楼梯，带行李要到中央东口（有电梯/扶梯），步行 6-7 分钟。攻略只笼统写"步行5-10分"，未区分出口。
☕ 周边：酒店旁有 NISHIMURA'S COFFEE（西村咖啡）；右边小路几分钟到商业街；KOHYO 生活大超市在三宫站东口；门前一条路餐厅遍布、神户牛店在不远路口；全家/7-11/罗森随处补货。
🧴 备品：一楼有备品区（含面膜、保养品旅行组），不止基本洗漱；房间电视可看 Netflix；无瓶装水，可向前台索取。
🍳 餐饮：早餐咖喱饭好吃；退房后可寄存行李，不影响当天行程。
🕒 入住/退房（官网核实）：入住 15:00 / 退房 11:00；提前入住（11:00 前）收前晚房费、11:00–15:00 每小时 ¥1,000；延迟退房 11:00–18:00 每小时 ¥1,000。
🧳 行李寄存流程（提前寄存 / 取回 · 携程·Klook·TripAdvisor 交叉核实）：

• 退房当天寄存：11:00 退房后把行李交前台免费寄存，晚上看花火/逛街前取走（Day 1 红眼落地、Day 3 退房都可用）。
• 费用：前台寄存 免费，住客常态使用、无明确时长上限。

② Minn 祇园三条（Day 4-6）

🛎️ 入住避坑（重要）：基本自助办理，提前发的登录密码几乎没用，需人工视频客服（仅日语/英语，无中文）。无出行经验者不推荐独自操作。

🦟 注意：虫子多，第一晚被蚊子咬，建议带驱蚊。附近有同连锁另一家别混淆。
🕒 入住/退房（官网核实）：入住 15:00（夜间任意时间可自助办理，需手机/平板或视频客服）/ 退房 10:00（可延时至 12:00，视房态收费、需预约）。注：部分 OTA 显示 11:00，以官方/预订确认为准。
🧳 行李寄存流程（提前寄存 / 取回 · 携程·Trip.com·itravelblog 住客实测）：
• 提前寄存（到店早于 15:00）：拖行李到 1F 大堂自助行李寄放区（Minn 本就自助式，无传统 bell 柜台）→ 放入即免费寄存，几乎不会满位。
• 取回：返店后到 1F 同一寄放区自取；若入口/寄放区上锁或不会用，呼叫 值班人员 或线上视频客服协助（15:00 起必有值班）。
• 退房当天寄存：10:00（可延至 12:00）退房后，行李仍可在 1F 自助区暂存，去祇园/锦市场轻装逛完再取。
• 注意：记得带好房门密码/APP；寄存与入住互不冲突，先寄存再慢慢办入住。
• 📱 小红书真实体验：住客实测自助寄放区用密码锁存取（有人问"密码锁设定后怎么打开"），操作不熟可叫15:00后值班或视频客服；退房后行李可寄存到晚上（有住客确认可暂存至晚，去祇园/锦市场轻装逛完再取）。
⚠️ 到站出口说明（已核实）：酒店最近站是地铁东西线「三条京阪站」（月台在地下4楼），从①号出口步行 2 分钟（约180m）即到——最优选。注意别和京阪电车的「三条站」搞混：两站不同铁路系统、出口编号不同，但地下通道相通、不用重购票；若坐京阪电车在「三条站」下，走地下通道到三条京阪站再走①号出口，合计约 4–5 分钟。坐地铁来的（如 Day 4 京都站→乌丸线→乌丸御池→东西线）直接认①号出口即可。

🛂 入境与海关指引（内地居民版）

🇯🇵 一、日本入境（关西 KIX · 8/15 落地）

📋 出发前需准备

📋 Visit Japan Web（VJW）：日本官方免费服务（数位厅），非强制但强烈建议。出发前 7–14 天在线填好护照 / 航班 / 首晚住宿 → 生成统一 QR（入境审查 + 海关申报二合一），到机场扫一次过两关，旺季省 30–40 分钟。一个邮箱注册，3 人可同一账号加"同行家人"（限配偶 / 直系血亲；成年朋友需各自账号），每人独立 QR，不能共用。
📋 二维码双备份：打印 + 手机截图各一份；屏幕调亮；护照号须与护照完全一致，住宿地址精确到门牌（用邮编自动带入）；航班 / 酒店改了要重新登录生成 QR。
📋 日本旅游签证：中国大陆护照仍需先办日本旅游签证（VJW 不是签证！），务必行前办妥。
📋 现金 + 交通卡：备足日元现金（人均 5–8 万）+ 信用卡；落地机场买 ICOCA / Suica，很多小店只收现金。

⚠️ 注意事项（海关 / 申报 / 禁带）

⚠️ 现金申报：现金或有价证券超过 100 万日元须另填"支付手段等输入输出申报书"。
⚠️ 免税额度：成人酒 3 瓶(760ml) / 烟 200 支或雪茄 50 支 / 香水 2oz / 其他境外市价合计 ≤ 20 万日元（单件 ≤1 万日元不计入）。
⚠️ 带娃常用药：含 pseudoephedrine（伪麻黄碱）等成分的感冒药 / 鼻炎药属日本管制，超量需事前办"医药品证明书（yakkan shoumei）"；Adderall / Vyvanse 类兴奋剂严禁携带。
⚠️ 禁带：肉类 / 生鲜农产品（非洲猪瘟防范，最高罚 300 万日元或 3 年监禁）、毒品、武器。
